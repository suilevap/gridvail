# DejaVu Sans Mono

Bundled unmodified from Matplotlib v3.10.0:
https://github.com/matplotlib/matplotlib/tree/v3.10.0/lib/matplotlib/mpl-data/fonts/ttf

`LICENSE_DEJAVU` contains the redistribution terms and copyright notices.
This font supplies the Unicode box-drawing and direction symbols missing
from Bevy's default font subset.
