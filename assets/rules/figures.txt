# Figures: objects drawn as a few small upright glyphs placed together so
# they read as a shape, by renderers that show height (the text renderer's
# `--walls stacked` and `--walls leaning`), in place of their one glyph.
# Flat renderers draw the glyph as before.
#
#   figure NAME
#   view front|back|left|right
#   LABEL GLYPH [options]
#
# A figure has parts for each way it is seen facing on screen: toward the
# viewer (front, also for objects that face no way), away (back), or to a
# side. Parts before any `view` line are the front; a side not drawn is the
# other side mirrored, and a view not drawn shows the front. Parts are drawn
# back to front, in the order listed.
#
# LABEL names the part for the reader. GLYPH is one character, or `own` for
# the object's own glyph. Options:
#   x=X y=Y        where the glyph's centre is, in cells from the centre of
#                  the object's cell, on screen: x to the right, y up
#   scale=S        the glyph's size, 1 for a whole cell (default 0.5, the
#                  font's own size)
#   turn=DEGREES   turned counter-clockwise
#   shade=S        how much of the light it shows, 0 to 1 (default 1)
#   tint=#rrggbb   a colour the light is multiplied by, instead of a shade
#   only=GLYPHS    drawn only while the object's glyph is one of these
#   noflip         where its side is drawn mirrored, the glyph keeps its own
#                  way round (its place still mirrors), for glyphs read as
#                  themselves, such as @
